# 365 AI Master · 视觉研究

高级感来自秩序与一致性。占比及尺寸为本次建议，非官方规范。

## 参考与转译

- [Rams / Braun](https://www.vitsoe.com/us/about/good-design)：克制、易懂；中性色底、明确操作色。
- [Swiss / Müller-Brockmann](https://swissgrid.posterhouse.org/)：网格、非对称、无衬线。统一左边界，以字号和空白组织内容。
- [Bauhaus](https://bauhauskooperation.de/en/knowledge/the-bauhaus/training/workshops/printing-and-advertising-workshop)：几何统一传播；●■▲ 对应身份，避免三色平分。
- [Teenage Engineering](https://teenage.engineering/products/op-1)：借仪器标注与局部色彩。
- [Nothing OS](https://nothing.tech/nothing-os)：统一图标与字体；当前含透明组件与 Geist。借秩序，不套点阵字。
- Apple：[组件](https://developer.apple.com/design/human-interface-guidelines/widgets)、[Control Center](https://support.apple.com/en-ie/guide/mac-help/mchl50f94f8f/27/mac/27)。Weather 借主数据与环境底色，Stocks 借紧凑列表；[Fitness](https://www.apple.com/uk/watch/close-your-rings/) 借进度环。Fitness 非 Mac 原生 App。借半透明外壳、语义色环。
- [Things 3](https://culturedcode.com/things/)：轻分区与列表节奏。[Linear](https://linear.app/now/behind-the-latest-design-refresh)：稳定导航及操作位置。[Raycast](https://www.raycast.com/blog/a-fresh-look-and-feel)：紧凑清晰。[Arc](https://start.arc.net/find-focus)：内容优先。
- Geist 的[颜色](https://vercel.com/geist/colors)按用途分工；[排版](https://vercel.com/geist/typography)将组合排版令牌。

## 执行建议

按可见面积含背景估算：A 灰阶97%/蓝3%；B 中性94%/朱红5.5%/蓝0.5%；C 中性材质94%/青绿6%。强调色服务动作、选中、进度。

SF/PingFang SC，数字 tabular-nums。辅助11–12、正文13、标题17–25、大数64–96px；400/500/600为主。

4px 网格、边距20–24、区块间距16–24。A 留白与单线；B 平面与结构线；C 柔和圆角与材质。阴影只解释浮层，避免嵌套卡片。

反馈120–160ms，无循环动画，支持减少动态。深色重配底、线、字与强调色，禁止反相。HTML 可切深浅；CSS 材质需在 macOS 验证。
